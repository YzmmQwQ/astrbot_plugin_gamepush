## 安装方法

使用 GitHub

```shell
git clone https://github.com/rainbowwarmth/GamePush-Plugin ./plugins/GamePush-Plugin
```

使用 Gitee

```shell
git clone https://gitee.com/rainbowwarmth/GamePush-Plugin ./plugins/GamePush-Plugin
```

使用 Gitcode

```shell
git clone https://gitcode.com/rainbowwarmth/GamePush-Plugin ./plugins/GamePush-Plugin
```

## 使用方法

1. 发送`#星铁开启版本推送`即可开启星铁版本检测推送
2. 发送`#星铁获取(预)下载链接`可获取星铁 PC 游戏的(预)下载链接

## 注意

· 原神从 5.6 版本开始不提供(预)下载的压缩包链接下载方式，此命令`#原神获取(预)下载链接`无法使用
